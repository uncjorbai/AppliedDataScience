# Machine Learning: Recidivism Fairness & Applied ML

**Course:** DATA 780: Machine Learning · **Stack:** Python, scikit-learn, TensorFlow

A fairness study of algorithmic recidivism prediction, and a companion to the AI governance
capstone in [project 07](../07-governance-nist-capstone/).

## Final project: fairness in recidivism prediction (COMPAS)

Co-authored with Scott Smith and Chris Gonzales.

Examines machine bias in COMPAS-style recidivism models and evaluates disparate impact using
the 80% rule and the balanced error rate (BER), then applies ratio-based debiasing toward
statistical parity. Connects the fairness metrics to the real stakes of sentencing, parole,
and resource allocation.
